# Changelog


## 1.3.0 — Sakura UI Refresh
- Refined the main inventory layout with clearer navigation, item-grid, search, and inspector panels.
- Refined the enchantment editor with dedicated search, registry-row cards, and a clearer selection summary.
- Reworked the Sakura panel texture with a deeper plum glass palette, rose-gold framing, corner blossoms, and subtle star accents.
- Refreshed the drifting petal sprite and ambient petal/sparkle motion.
- Added visual emphasis for hovered/selected item slots and current screen status.
- UI-only update: command registration, key mapping, item catalog, enchantment filtering, quantity handling, and item-drop service were not changed.

## 1.2.0 — Registry Enchantments & Quick Key
- Replaced the fixed enchantment list with entries discovered from the active world's enchantment registry.
- Added modded enchantment discovery for compatible utility/defensive enchantments, search by display name or namespaced ID, and pagination.
- Added level editing from 1 to 255 for each selected supported enchantment.
- Added a configurable key mapping (default K) under Options → Controls → Key Binds → Advanced Inventory.
- Kept `/inv` available as an alternative opener and retained the Singleplayer-only behavior.
- Weapon/combat-oriented enchantment entries remain excluded from the editor.

## 1.1.0 — Sakura Edition
- Added registry-driven discovery for compatible modded items.
- Added All / Modded / Vanilla categories.
- Added Sakura floral panel artwork and animated drifting petals.
- Added pulsing title/highlight and Vietnamese UI labels.
- Rethemed the enchantment screen to match.
- Updated project version to 1.1.0.
